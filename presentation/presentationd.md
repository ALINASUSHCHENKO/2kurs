- Криптографии

# Основная часть

## Что такое Хеш-функции?  
**Хеш-функция** — алгоритм, преобразующий данные в строку фиксированной длины (хеш). 

### Свойства:  
1. **Детерминированность** — одинаковые данные → одинаковый хеш.  
2. **Односторонность** — невозможно восстановить исходные данные из хеша.  
3. **Лавинный эффект** — малые изменения данных → полностью новый хеш.  
4. **Устойчивость к коллизиям** — крайне низкая вероятность совпадения хешей для разных данных.  

**Примеры алгоритмов**:  
- `SHA-256` (Bitcoin)  
- `MD5` (устаревший)  
- `SHA-3`, `Blake3`. 

## Для чего используются Хеш-функции?  
### Основные задачи:  
1. **Проверка целостности**  
   Сравнение хешей до/после передачи файла.  
2. **Безопасность**  
   - Хранение паролей в виде хешей.  
   - Цифровые подписи для документов.  
3. **Блокчейн и криптовалюты**  
   Хеши связывают блоки, обеспечивая неизменность транзакций.  
4. **Оптимизация поиска**  
   Хеш-таблицы → поиск данных за O(1).  

## Практическое применение  
### Примеры:  
- **Загрузка ПО**  
  Сайты публикуют хеши (например, `SHA-256`) для проверки подлинности.  
- **Git**  
  Коммиты идентифицируются уникальными хешами.  
- **Антивирусы**  
  Хеши вредоносных файлов в «чёрных списках».  
- **Дедупликация**  
  Экономия места в облаках за счёт хранения уникальных хешей.  
- **Криптовалюты**  
  Майнинг Bitcoin основан на поиске хешей (Proof-of-Work).
